## 索引与展示的约定

- 原始标题、摘要、作者、报告、代码和来源链接均保留。检索按字段加权：标题最高，其次模型 / 项目身份、作者与组织，最后摘要与方向同义词。
- DOI、arXiv、完整来源 URL、历史 work ID 使用精确身份映射。裸 `PI` 表示 Physical Intelligence 公司；裸 `π0` / `pi0` 表示标题或项目身份确认的模型族；`π0.5` / `pi0.5` 限定具体版本。TeX 写法 `$π_0$`、`$π_{0.5}$`、`\pi_{0.5}` 和 Unicode 下标均规范化。不依靠 D1 标签推断身份，不将摘要中单纯引用 π 模型的工作自动归入模型身份。
- 构建和查询均显式使用中文词边界，避免“灵巧操作”在完整索引上产生分词不一致。英文 stemming 对照没有明显缩小倒排，因此发布仍采用中文 Pagefind 索引。
- 英文功能停用词在构建和查询时一致处理。否定词、数字、技术词和中文内容不会作为停用词移除。
- 摘要使用词项集合：已在高权重标题 / 中文摘要出现的词不在英文摘要中重复登记，同一摘要中同一个英文词只保留一次。完整原文始终可查看和下载，每个独立词仍可检索；摘要内的重复词频和连续短语位置不是本检索器承诺的能力。
- 索引通过 Pagefind 的公开 `getFiles()` 与搜索 API 生成。用唯一数字 ordinal 排序导出 result handle 映射，并校验数量、唯一性和分布位置。没有读取或重写 `.pf` 私有压缩格式。
- 发布时不保留 Pagefind 的重复全文 fragment / filter 文件。前端不会调用原生 `result.data()` 或 `pagefind.filters()`，对应加载由自己的公开结果与筛选 API 承担。

## 正确性与剩余验收

`tests/v3-search.test.mjs` 已通过 11 项测试，包括 617 条真实 Pagefind 中文 / 英文 WASM 索引、1203 个 handles 的第 26 页和最后一页、全部纳排状态、中文词 / 特殊符号 / 作者 / DOI / 来源 URL、PI 前缀噪声、同一 manifestation 的会议筛选、跨月 OR 筛选、URL 往返、摘要词项覆盖。

π 模型测试不再以“有结果”为通过条件。采用真实标题 `$π_0$: A Vision-Language-Action Flow Model for General Robot Control` 与 `$π_{0.5}$: a Vision-Language-Action Model with Open-World Generalization`；全库运行时检查要求 `π0` / `pi0` 必须召回 `arxiv:2410.24164`，`π0.5` / `pi0.5` 必须召回 `arxiv:2504.16054` 且不混入原始 π0。上方体积与请求数据保留为修复前的性能基线，应在重建后复算；基线中的“π0 有命中”不能证明关键论文召回完整。

测试还会移除所有 fragment / 原生 filter 资产，再运行适配器查询；任何错误请求这些文件都会失败。全库诊断额外验证全部实体的映射与第 26 页可达，而不是用小样本替代完整库构建。

前端提供完整结果 handles 的 20 项分页、可复制筛选 URL、前进 / 后退恢复、移动折叠筛选、原生 dialog 焦点约束 / Escape / 回焦。**真实桌面和移动浏览器的布局、导航和网络验收仍须由整站测试完成**，本文件不把类型检查或本机 WASM 速度当作这些验收的替代。
