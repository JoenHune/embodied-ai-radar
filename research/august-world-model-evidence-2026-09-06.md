# 八月世界模型研究证据补强稿

研究窗口：2026-08。原文检查：2026-09-06。整理者：Codex AI；不是人工专家批准、Responses API 生成记录或独立实验复现。本稿补充实验阅读，不替代完整月报，也不改动趋势成熟度。

## 可以形成的月度判断

八月的这组研究把世界模型从“视频是否逼真”推进到更具体的问题：动作是否被执行、虚拟评估能否保留真实策略排序、预测表征能否改善控制。WorldSync、WALL-SS 与 CLAP 提供不同设置的实验，但不能合并成同一可比 benchmark，也不能从同一论文的多个实验虚增独立证据数。

最值得强调的变化是**控制效用开始有具体检验方式，同时模型误差的后果也被显式报告**，而不是据此宣布世界模型路线已经成熟。下文区分作者结果、作者限制和本雷达的解释边界。

## 四项工作与实验边界

### WorldEcho / WorldSync：固定预算下的策略改进

- work：`arxiv:2608.24885`；首发及所读版本：2026-08-25，v1。方向 D3/D12；对应命题 S1。
- 实验：全文§4.4保持同域初始策略、交互、生成与训练预算相同，改变世界模型条件。真机堆杯中，两组由48%起步，两轮后 WorldSync为68%、CtrlWorld为56%。
- 边界：这是特定任务的作者实验，不是普遍控制收益或独立复现。§4.5显示组件收益并不一致；§5承认更长时序、多本体和开放环境仍需检验。
- 月报表述：动作跟随对齐出现了可对照的真机效用证据；需扩展任务和独立验证后才能升级为路线结论。

来源：[v1原文§4.4–5](https://arxiv.org/html/2608.24885v1#S4.SS4)、[版本历史](https://arxiv.org/abs/2608.24885)。原文链接的章节锚点若因渲染变化失效，可按章节号定位。

### WALL-SS：预测时长、评估一致性与控制表现必须分开

- work：`arxiv:2608.26239`；首发及所读版本：2026-08-26，v1。方向 D3；对应命题 S1/S4，映射为阅读建议，不覆盖现有分类。
- 实验：§6.3研究长时序视频预测；§6.5比较600组虚实配对轨迹；§6.6由动作分支直接控制桌面双臂机器人。后者平均 Task Progress为69.1，不能写成69.1%成功率。
- 反向证据：虚实校准中，332次真实失败有45次被生成轨迹判断为成功；接触／插入阶段更乐观。这是同一论文的失败证据，不是外部反驳论文。
- 月报表述：同一模型同时探索预测、评估和控制接口，但三类指标不可混写；分钟级生成不等于分钟级持续自主执行。

来源：[v1原文§6.3–6.6](https://arxiv.org/html/2608.26239v1)、[版本历史](https://arxiv.org/abs/2608.26239)。

### CLAP：跨本体建模的控制用途已有实例，但比较条件不同

- work：`arxiv:2608.27406`；首发及所读版本：2026-08-27，v1。方向 D3/D9；对应命题 S1/S5，后者为阅读建议。
- 实验：§4.3在Franka上以多个策略产生动作候选，世界模型预测后由VLM评分；覆盖五项任务，每策略每任务20次试验。YAM另有双臂任务和动作接口适配。
- 边界：额外候选策略、规划和评分计算存在，不能直接当成固定计算预算的纯世界模型消融。§5明确承认幻觉风险；未见本体的视频泛化、少样本适配与真机规划不是同一命题。
- 月报表述：跨本体预测开始服务于真实规划；应同时报告候选策略、评分器、动作接口和推理成本。

来源：[v1原文§4.2–5](https://arxiv.org/html/2608.27406v1)、[版本历史](https://arxiv.org/abs/2608.27406)。

### Zero-WAM：人类视频既是数据，也可能是任务接口

- work：`arxiv:2608.26103`；首次公开2026-08-26；所读v2公开2026-08-27。方向 D9/D4；对应命题 S3。
- 实验定位：不仅扩大预训练数据，还以人类视频指定未见任务。HumanGen含由机器人轨迹生成的人类视频，不能全部写成自然采集的人类第一视角数据。
- 边界：主比较同时涉及预训练和提示条件；§4.4另有提示、IFP、任务平衡消融，不能写成“没有消融”。真机试验使用已见配置示教适配Franka，再测试未见配置，不等于完全无需机器人数据。
- 月报表述：需分开研究“视频提供了更好的任务说明”与“人类数据规模改善了可迁移物理先验”。完整数值对照见同轮部署证据稿。

来源：[v2原文§4.2–4.4](https://arxiv.org/html/2608.26103v2)、[版本历史](https://arxiv.org/abs/2608.26103)。

## 月报与可视化的使用规则

| 展示内容 | 本批证据可支持 | 不可升级为 |
|---|---|---|
| 世界模型控制效用 | 每篇自己的任务、预算和对照 | 不同设置的统一成功率排名 |
| 长时序 | 明确区分预测长度、记忆窗口和实际执行长度 | “长视频=长时自主机器人” |
| 跨本体 | 训练数据、持出形态、适配及控制分别记录 | 数据集包含多本体就算跨平台复现 |
| 反例与限制 | 作者失败分析、评估偏差、条件不匹配 | 没有读取过的负结果或外部反驳 |
| 证据数量 | 每个canonical work全局计一次 | 同论文多个实验、模型与项目页重复计数 |
