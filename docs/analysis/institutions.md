## 读表原则

- 产量不是唯一质量指标；持续跨月、跨方向和独立评审证据更重要。
- arXiv 通常不含 affiliation，本页只使用官方 proceedings 和已核验作者/项目页。
- “团队”按论文作者组合与独立项目线判断，不将同一系列版本重复视为独立验证。
