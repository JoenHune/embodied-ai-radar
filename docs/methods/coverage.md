# 研究组覆盖与发现口径

组织雷达同时公开“已登记多少来源”“最近实际核验多少来源”“高信号工作有多少完成研究组归属”。这些数字有不同分母，不能相互替代，也不能证明已覆盖全球全部公开研究。

## 来源覆盖

登记的主页、论文页和其他研究发布渠道都保留在分母内。只有实际检查成功、检查日期有效且未超过检查周期的来源，才计入近期已核验。仅在组织档案里填写了网址，不等于已检查成功。

T0/T1 使用七天检查周期；T2 使用三十一天周期。连续两次失败或超过两个检查周期未核验时显示过期提醒，并保留已有记录。重复网址按“组织与网址”去重，同一网页为不同组织提供证据时仍分别展示其归属。

## 研究归属

高信号归属率的分母是过去十二个月内首次公开、已纳入并具有精读、严格同行评审、E1–E4 或技术报告证据的 canonical work；分子是其中至少具备一个有效 G1/G2 研究执行单元归属的 work。联合论文只计一次。无法确定日期或仍待相关性复核的工作不纳入这一分母。

论文只写 NVIDIA 不足以归入 GEAR，只写 CMU 不足以归入 Robotics Institute。来自 affiliation 的发现只形成 G0 母机构观察；实验室人员归属必须有独立证据，G2 还必须具有与论文日期重叠的官方成员关系。Physical Intelligence 与 MPI-IS 同名部门保持歧义待核验，不能凭简称 PI 合并。

## 动态发现与晋级

未知 affiliation 可以进入 T2 发现池，但不会自动得到虚构的主页、负责人或实验室归属。已登记的 T2 研究执行单元，只有同时具备近期检查成功的官方发布渠道，并在过去十二个月积累两项不同的 G1/G2 相关工作，或一项 E2 以上工作，才可晋级 T1。母机构节点不会因 affiliation 数量被升级成执行组。

T0 核心组织始终显示。没有新论文、来源暂时失效或归属尚未核验时，页面显示缺口，不将组织从雷达中移除。

## 冻结样本与全体召回率

官方发布召回率需要可审计的独立发布清单作为金标准。当前没有覆盖全球研究组的完整金标准，因此该值显示“未测量”，不会把来源可访问率、已有工作匹配率或目标值写成已经达到的召回率。

T0 官方回归样本召回率至少 95%、高信号工作具体组归属至少 90% 仍是验收目标，不因暂时缺证而降低。待归属核验采用固定工作清单，逐项记录已确认关系或未完成原因；复核不能通过静默删除未匹配项来提高分子占比。

分层回归使用先于数据库匹配冻结的官方发布样本。[逐项结果](/api/v1/release-recall.json) 与 [原始样本及来源证据](/api/v1/coverage-gold-releases.json) 同时公开，SQLite 的 `release_recall_gold` 表提供相同分母。当前回归框架覆盖指定的十二个核心组，不是全部核心组或互联网发布普查。

发布检查要求研究发布至少 95% 能以硬身份／官方发布链接绑定到唯一 canonical work 的 manifestation；仅找到标题、仅保存一个没有绑定的来源链接、出现多个重复 work，均不算通过。固定样本 hash 和最低样本规模由版本化政策保护，不能删掉难匹配项让结果变好。样本扩展须同时修订政策并保留旧基线。已绑定但候选／待分类／排除的记录保留在分母，并另报默认研究集可见率；采集召回通过不等于分类和实验结论已经审核通过。

## 复算入口与时间含义

[organization-coverage.json](/api/v1/organization-coverage.json) 提供窗口、分子分母、来源状态、待归属与发现池；[source-health.json](/api/v1/source-health.json) 提供实际检查记录。组织档案内的 `last_checked` 与全库 `data_through` 不是同一个字段，更不能把今天运行脚本当成所有来源都已更新到今天。

归属覆盖描述“当前登记事实是否能映射到组”；月度趋势的“当月可用证据”另按公开日期计算。某论文后来获得官方接收或归属证据，不意味着当月已经公开这些信息。详情见[时点与回看口径](/methods/#月份与两种证据视角)。
