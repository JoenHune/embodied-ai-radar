# 视觉设计与配图口径

本轮设计以“先看清，再展开，再读原文”为顺序。保留原有统计、研究判断和证据库，改变它们在页面中的层级。

## 七个入口的职责

- 总览：本期方向构成、研究与报告图文精选、12 个月趋势。
- 趋势：方向占比／数量切换；点击方向与月份，查看组成研究。
- 月度：执行结论与月际变化在前；图文工作流在中；完整 D/Q 解读和核验记录可展开。
- 人物与组织：照片卡、代表作、组织内连续工作；人物详情不打断原列表。
- 研究库：所有检索能力保留，结果以图文卡展示；原文为主出口，证据与版本为第二出口。
- 动态：研究发布的图文流；完整发布事件、证据升级和战略观察另层查看。
- 方法：纳排、来源健康度、数据下载与完整审计说明。

## 图片不是研究证据

人物照片来自本人或官方机构页对姓名与图片的明确绑定，不凭外貌识别人，也不使用生成照片代替真人。待消歧人物不自动配同名者照片。

论文和企业发布优先使用官方静态图、方法图或视频自带封面；不自动播放动图或视频。图与标题直接打开该工作的原文，不能用配图给研究提升证据等级。企业自述、正式评审、独立复现仍按原有数据模型分别处理。

媒体来源及观察日期见[配图来源索引](/api/v1/visual-media.json)。未声明再利用许可的图片保持“许可未知”，有摄影署名则保留。当前实现引用官方图片 URL，没有下载、转换或重新托管原图；官方来源不等于开放授权。

## 性能和缺图

图片预留固定尺寸、按需加载。超过 4 MB 的人物原图和超过 2 MB 的研究配图延后到主动打开；无图、加载失败或身份待确认时保留清楚的文字入口，不制造装饰图，也不删除研究。

“图文精选”仅是已核验官方配图的代表性样本，不是研究排名或全部研究。按月选择器与完整研究库保留原有收录范围；组织筛选不能把范围外工作带入该组。

图表联动的信息流按主方向筛选，与占比分母一致；卡片仍显示交叉方向标签。配图为当前核验的官方资料，不声称当前图片文件在论文首次公开时已存在，也不据后补图片改写历史研究证据。
