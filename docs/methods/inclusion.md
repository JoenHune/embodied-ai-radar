# 纳入、排除与研究局限

## 纳入规则

候选必须同时满足：

- 研究对象位于机器人或具身交互边界内；
- 方法直接学习、生成、规划或执行动作，或为这些能力提供数据与动力学模型；
- 标题、摘要或正式方法说明能支持至少一个主方向；
- 首次公开时间落入已登记语料窗口；趋势默认展示最近 12 个完整自然月，当前月暂行展示。

## 典型边界样本

| 情形 | 处置 | 原因 |
|---|---|---|
| VLM 为机器人生成任务计划，低层策略执行 | 纳入 D2 | 实际形成高层推理—低层控制分工 |
| 机器人视频模型只展示生成质量 | 不进入动作/控制趋势 | 未证明对动作、规划或控制有用 |
| 动作条件视频预测用于 MPC 或策略训练 | 纳入 D3，可加 D8 标签 | 与交互决策有直接因果链 |
| 通用 diffusion policy 在多个机器人上训练 | 纳入 D8，可加 D1 标签 | 主贡献是策略学习与迁移；D5 专指人形、运动与全身控制 |
| 单任务 PID / MPC 性能改进 | 排除 | 不属于计划关心的可迁移学习能力 |
| 自动驾驶 world model | 默认排除 | 本期不覆盖纯自动驾驶 |
| 纯 SLAM / visual odometry | 排除 | 不直接学习具身动作能力 |
| 新灵巧手机械结构，无学习方法 | 仅在硬件生态提及 | 不计入论文趋势总量 |
| 纯数学图解或视觉 CoT，尚无具身迁移验证 | 保留为方法参考，排除正式趋势计数 | 生成模型中的 action / policy 术语不等于具身动作链路 |

## 置信度

- `high`：标题与摘要存在多个一致信号，边界清晰。
- `medium`：属于具身学习，但主方向需要方法级判断。
- `low`：仅由单个关键词命中或摘要信息不足；不得直接作为趋势数量证据，须先完成有来源定位的相关性复核，并明确标识 AI 与人工复核。

相关性状态与组织归属、发表状态分别保存。G1/G2、知名研究组或主会接收都不能跳过纳排规则。主方向平局、最高两项分差不超过 1、缺少可靠主方向时进入复核；当前 included work 必须有唯一主 D。未纳入记录不删除，数据库可显式选择 candidate、manual_review、excluded。

全文支持的 AI 分类复核会绑定原文版本、阅读回执、逐字段理由与定位，公开变更前后值及修订记录；不冒称人工审稿或独立实验验证。原始机器评分、论文日期和发表状态不因分类复核被改写；后续采集也不能静默覆盖已复核字段。统计始终由规范化记录确定性计算，而非由摘要模型填写数字。

Q 标签和“真机、跨本体、长时序”等词项用于检索召回；能力升级必须使用有公开日期、来源和审核状态的实验证据。关键词密度不能证明能力已经实现。

## 已知局限

1. **登记来源不是学术全集。** 部分工作先出现在会议 proceedings、机构技术报告或项目页；v3 将这些来源统一为 canonical work。首次公开与后续接收、出版、开源、复现分别记录，后续事件不改写首次公开月。
2. **摘要标签偏保守。** “真实机器人”“开源”“跨本体”等证据若只写在正文或补充材料中，自动标签可能出现假阴性。
3. **机构信息不完整。** arXiv 元数据本身通常不含 affiliation；母机构线索与实验室 G1/G2 归属分开，并显示有效覆盖。当前成员关系不能倒推历史归属。
4. **近期同行评审覆盖率天然偏低。** 这可能同时反映发表滞后、采集覆盖或日期证据缺失，不能直接解释为研究质量下降。按月视角不倒灌后来评审，“今天回看”另行呈现同一批研究的后续验证。
5. **会议周期会造成提交堆积。** 月度页面对显著集中提交做备注，不把截稿周期自动解释为技术爆发。
6. **百分比受小样本和不完整窗口影响。** 所有图表保留绝对数量；暂行月不进入完整月动量判定，分类待定数与来源缺口同时展示。
7. **一句话贡献与局限是研究判断。** 它们不是作者原文，站点将其与可核验事实分开表述。
8. **旧索引的局限仍保留为迁移背景。** 早期 arXiv Atom 限流后曾使用 Semantic Scholar 的 arXiv external ID 索引，不能据此宣称 cs.RO 全集。v3 的覆盖完整性以登记来源的分页、计数与失败状态核验为准。
9. **未知与零值不同。** 当前暂行月尚无数据时不作为折线零点；年份或日期未知记录不被强塞到某个月，来源失败也不表示该组没有发表。
10. **自动摘要不是事实权威。** 摘要依赖的来源或证据包变化时需重新核验；旧文件保留，但失效文本不继续覆盖新统计。模型不可用时提供数据版，不用无依据叙述填满所有方向。

当前分类、月度证据和待核验工作分别可在[方法总览](/methods/)、[月度账本](/monthly/)和[研究数据库](/database/)查看。

## 研究边界与仍待完成的范围

市场规模估算、融资估值分析、商业订单验证、供应链和公司级尽调不在本期范围。本报告只提供研究证据，可作为后续商业模块的技术底座。

公开招聘、融资、组织变化和企业 Demo 可在战略观察中保留，但不是正式研究趋势计数。十二个月的全面研究总结、关键公司与课题组的持续覆盖、技术报告、趋势验证、免费静态搜索、可视化体验、周更与飞书交付仍在完整计划内；尚未实现或验收的部分必须明示，不能改称“非目标”。
